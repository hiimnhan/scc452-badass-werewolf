Night Phase:
- Primary Objective: Secure the information pipeline.
- If Guard: Protect the claimed Seer exclusively. Rotate to a Seer-cleared player ONLY when the 'no consecutive protection' rule applies, then return to the Seer immediately. NEVER protect self while Seer is alive.
- If Seer: Investigate unverified players. Prioritize those exhibiting 'logic posturing', 'vibe traps', or those remaining silent during high-pressure debates.
- If Witch:
  - Save: Prioritize the claimed Seer. Coordinate with Guard during Day Discussion to avoid redundancy.
  - Poison: Use on confirmed wolves or the last remaining unverified variables when the pool is reduced to 2-3 players to accelerate victory.

Day Discussion:
- Role Claiming: IF I am a power role, claim early to establish a 'Power Core' and stabilize the village.
- Data Delivery: Deliver factual data decisively. Do NOT mirror the Seer's phrasing or simply validate data without adding original analysis, as this is a wolf signal.
- Power Core Defense: IF the Seer is attacked for tone or aggression, IMMEDIATELY redirect the group to factual investigation results.
- Wolf Detection (Logic Posturing): IF a player echoes Seer data without original analysis or claims patterns without evidence, THEN flag as wolf.
- Wolf Detection (Vibe Trap): IF a player attacks the tone/process of the debate to deflect from logic, THEN flag as wolf.
- Wolf Detection (Pseudo-Logic): IF a player uses complex jargon (e.g., 'mechanical inconsistency') to frame innocents or contradict the PoE, THEN highlight the factual contradiction.
- Pressure Application: IF the variable pool is silent, demand specific deductive value or role claims.
- Process of Elimination (PoE): Prioritize PoE over behavioral analysis in the endgame. Focus exclusively on unverified variables once a core group is cleared.
- Legacy Data: IF the Seer is eliminated, advocate for the absolute use of their confirmed clears.

Voting Phase:
- Target Priority:
  1. Seer-confirmed wolves.
  2. The last remaining uncleared variable (PoE).
  3. Players utilizing 'Logic Posturing' or 'Pseudo-Logic'.
  4. Players using 'vibe-based' deflections.
  5. Players steering votes toward Seer-cleared players.
- Verification: NEVER vote for a player cleared by the Seer.
- Role Conflict Resolution: IF multiple players claim the same role, prioritize the Seer-cleared claimant; target the uncleared claimant.
- Pivot Logic: IF a Seer-cleared player is exiled, immediately target the orchestrators of that vote.
