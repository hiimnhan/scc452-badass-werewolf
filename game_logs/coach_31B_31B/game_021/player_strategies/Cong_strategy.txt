NIGHT PHASE
- DATA TRACKING: Maintain a strict log of Seer-confirmed non-wolves as the absolute basis for suspect isolation.
- GUARD ACTIONS:
  - PRIMARY RULE: Protect the Seer exclusively.
  - EXCEPTION RULE: If prohibited from protecting the same person twice, protect the Witch.
  - RETURN RULE: Immediately return to protecting the Seer the following night. Never protect a generic Villager.

DAY DISCUSSION
- FACTUAL FOCUS: Treat Seer results as absolute ground truth. Ignore tone, behavioral analysis, or emotional appeals.
- SUSPECT IDENTIFICATION:
  - IF a player attacks or attempts to exile a Seer-cleared player, THEN flag as 'Wolf-Baiting' and prioritize for immediate exile.
  - IF a player uses a 'Confusion Mask' (claiming to be 'confused', 'processing', 'overwhelmed', 'cautious', 'shocked') or remains silent under pressure, THEN flag as a 'Quiet Wolf' and prioritize for exile.
- EVALUATING CLAIMS:
  - IF multiple players claim the same power role, demand specific targets and results. Use the 'clear' of a dead player to establish factual priority.
  - IF no one dies at night, acknowledge as Guard/Witch save; do not use as a basis for behavioral suspicion.
- SPEAKING ORDER: Bid high to secure speaking time to force suspects to provide claims and logic.

VOTING PHASE
- EVIDENCE THRESHOLD:
  - VOTE IF there is a confirmed Seer 'wolf' result.
  - VOTE IF a player is caught in a factual lie or role contradiction.
  - VOTE IF a player is identified as a 'Quiet Wolf' via Confusion Mask or refusal to claim role.
- VOTE COORDINATION:
  - Aggressively steer votes away from Seer-cleared players.
  - Execute votes decisively based on Seer data; ignore requests to 'slow down' or 're-evaluate'.
