Voting Phase:
- Target Priority:

  2. Players exhibiting Tonal Gaslighting (attacking the Seer's communication style).
  3. Players exhibiting Social Mimicry (if not Seer-cleared).
  4. Players using deflection tactics to frame basic Villagers.
  5. The 'Last Variable' (final uncleared player).

- Pivot Logic: If a Seer-cleared player is exiled, immediately target the primary orchestrators of that vote as wolves.
