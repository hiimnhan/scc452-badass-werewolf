Night Phase:
- Primary Objective: Absolute protection of the information pipeline.
- If Guard: Protect the claimed Seer every night. Strictly rotate to a Seer-cleared player only when the 'no consecutive protection' rule applies, then return to the Seer immediately. NEVER protect self if the Seer is alive.
- If Seer: Investigate unverified players. Prioritize those exhibiting 'logic posturing', 'vibe traps', or those remaining silent during high-pressure debates.
- If Witch:
  - Save: Use the save potion on the claimed Seer or the most critical information asset. Coordinate with the Guard during Day Discussion to avoid redundant protection/saving.
  - Poison: Use the poison potion only on confirmed wolves via Seer data or logically certain targets identified via PoE.

Day Discussion:
- Role Claiming: IF I am a power role, claim early to stabilize the village and establish a 'Power Core' before the Seer is targeted.
- Data Delivery: Deliver factual data decisively. Avoid echoing the Seer's exact phrasing to avoid 'Quiet Steerer' accusations.
- Power Core Defense: IF the Seer is attacked for tone, style, or 'aggression', THEN immediately redirect the group to the factual investigation results.
- Wolf Detection (Logic Posturing): IF a player echoes Seer data without original analysis or claims to 'see patterns' without evidence, THEN flag them as a wolf.
- Wolf Detection (Vibe Trap): IF a player attacks the tone of the debate to deflect from logic, THEN flag them as a wolf.
- Wolf Detection (Pseudo-Logic): IF a player uses complex village terminology (e.g., 'mechanical inconsistency') to frame innocents or contradict the PoE, THEN highlight the factual contradiction.
- Pressure Application: IF the variable pool is silent, THEN demand specific deductive value or role claims to force errors.
- Process of Elimination (PoE): IF a core group is cleared, focus exclusively on remaining unverified variables. Prioritize PoE over behavioral analysis in the endgame.
- Legacy Data: IF the Seer is eliminated, advocate for the continued use of their confirmed clears.

Voting Phase:
- Target Priority:
  1. Seer-confirmed wolves.
  2. The last remaining uncleared variable (PoE).
  3. Players practicing 'Logic Posturing' or 'Pseudo-Logic'.
  4. Players using 'vibe-based' deflections.
  5. Players steering votes toward Seer-cleared players.
- Verification: NEVER vote for a player cleared by the Seer.
- Role Conflict Resolution: IF two players claim the same role, THEN prioritize the Seer-cleared claimant; target the uncleared claimant.
- Pivot Logic: IF a Seer-cleared player is exiled, THEN immediately target the orchestrators of that vote.
