NIGHT PHASE
- DATA TRACKING: Maintain a strict log of Seer-confirmed non-wolves. Use this pool as the only reliable basis for isolating suspects.
- ROLE-SPECIFIC ACTIONS:
  - IF Guard: Protect the Seer every single night. Do not protect yourself or other villagers while the Seer is alive. If the rules forbid protecting the same person twice, protect the most critical power role available, then return to the Seer immediately.
  - IF Seer: Investigate passive players to uncover wolves hiding in plain sight.
  - IF Witch: Prioritize the Save potion for the Seer to preserve factual intelligence. Use the Poison potion ONLY on players confirmed as wolves by the Seer. Never poison a player cleared by the Seer.

DAY DISCUSSION
- FACTUAL FOCUS: Treat Seer results as absolute ground truth. Ignore behavioral analysis, tone, 'vibes', or communication styles.
- SUSPECT IDENTIFICATION:
  - IF a player attacks or attempts to exile a Seer-cleared player, THEN flag them as 'Wolf-Baiting' and prioritize them as a primary suspect.
  - IF a player uses the 'Confusion Mask' (claiming to be 'confused', 'overwhelmed', or 'processing' to avoid taking a stand), THEN flag them as a 'Quiet Wolf' and increase their suspicion level.
- EVALUATING CLAIMS:
  - IF multiple players claim the same power role, demand specific targets/results to identify factual contradictions.
  - IF no one dies at night, acknowledge it as a Guard/Witch save and move on; do not use it as a basis for behavioral suspicion.

VOTING PHASE
- EVIDENCE THRESHOLD:
  - VOTE IF there is a confirmed Seer 'wolf' result.
  - VOTE IF a player has been caught in a factual lie or role contradiction.
  - VOTE IF a player is identified as a 'Quiet Wolf' using the Confusion Mask while others provide factual leads.
- VOTE COORDINATION:
  - Aggressively steer votes away from Seer-cleared players, regardless of their debate style or 'mirroring'.
  - Execute votes decisively based on Seer data; ignore requests to 'slow down' or 're-evaluate' when a wolf is identified.
