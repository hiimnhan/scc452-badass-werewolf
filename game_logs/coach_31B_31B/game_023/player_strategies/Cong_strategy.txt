NIGHT PHASE
- DATA TRACKING: Log all Seer-confirmed non-wolves; these players are the absolute baseline for trust.
- ROLE-SPECIFIC PRIORITIES:
  - IF Guard: Prioritize protecting the Seer above all other roles to preserve the village's only source of objective data.
  - IF Witch: Reserve the SAVE potion exclusively for a validated Seer. Use the POISON potion immediately upon a confirmed Seer 'wolf' result or a blatant role contradiction to eliminate threats without wasting a day vote.

DAY DISCUSSION
- FACTUAL FOCUS: Treat Seer results as absolute ground truth. Disregard tone, behavioral appeals, or emotional pleas.
- SUSPECT IDENTIFICATION:
  - IF a player attacks or attempts to exile a Seer-cleared player, THEN flag as 'Wolf-Baiting' and prioritize for immediate exile.
  - IF a player uses a 'Confusion Mask' (claims to be 'processing', 'observing', 'cautious', or remains silent during role calls), THEN flag as a 'Quiet Wolf' and prioritize for exile.
- EVALUATING CLAIMS:
  - IF multiple players claim the same unique power role (Seer, Witch, Guard), treat it as an objective admission of guilt by one party. Demand an immediate resolution via vote.
  - IF no one dies at night, acknowledge as a Guard/Witch save; do not use this as a basis for behavioral suspicion.
- SPEAKING ORDER: Bid high to secure early speaking time to force suspects to claim roles and provide logic.

VOTING PHASE
- EVIDENCE THRESHOLD:
  - VOTE IF there is a confirmed Seer 'wolf' result.
  - VOTE IF a player is caught in a factual role contradiction (e.g., double-Witch claim).
  - VOTE IF a player is identified as a 'Quiet Wolf' via Confusion Mask or refusal to claim role.
- VOTE COORDINATION:
  - Aggressively steer votes away from Seer-cleared players.
  - Execute votes decisively; ignore requests to 'slow down' or 're-evaluate' when factual contradictions exist.
