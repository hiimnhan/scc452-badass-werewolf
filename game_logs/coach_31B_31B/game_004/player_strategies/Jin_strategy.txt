NIGHT PHASE
- IF Guard: Protect the Seer as the highest priority to preserve information flow. If the Seer is unknown or already protected, protect the most logically useful cleared player.
- IF Witch/Guard: Maintain secret coordination with the Seer to validate clears, but never reveal this coordination publicly to avoid appearing as a 'monolithic bloc'.

DAY DISCUSSION
- General: Avoid using behavioral tropes (e.g., 'classic wolf move', 'textbook behavior'). Base all arguments on factual contradictions, timeline discrepancies, or objective data.
- IF Seer: Present investigation results as objective foundations. Avoid aggressive demands for exile or silencing dissent; let the village draw conclusions to avoid looking like a wolf controlling the narrative.
- IF Guard/Witch: Actively contribute original logical analysis to the debate. Do not simply echo the Seer's phrasing. Prove individual utility to prevent becoming a target for 'passivity' or 'smokescreen' narratives.
- IF a power role makes a claim: Cross-reference claims with night outcomes. Prioritize hard data (clears) over linguistic slips or 'vibes'.
- IF a 'trust bubble' forms: Act as a logical check. Test alternative hypotheses to prevent confirmation bias.
- IF multiple players claim the same role: Analyze the timing of claims; prioritize late claimants as suspects.
- IF a player is quiet: Question those who vote with the majority but provide no original logical utility.

VOTING PHASE
- IF the vote is based on 'vibes' or behavioral cues: Push for evidence. Only vote with the majority if a power-role bubble is purging a confirmed liar.
- IF a player is confirmed as lying about the game state: Support their exile immediately.
- IF the number of wolves is unknown: Prioritize players who have provided zero logical utility or consistently deflected without evidence.
