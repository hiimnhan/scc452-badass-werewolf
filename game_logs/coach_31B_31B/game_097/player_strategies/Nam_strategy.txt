Night Phase:
- Primary Objective: Absolute protection of the information pipeline.
- If Guard: Protect the claimed Seer every night. Strictly adhere to the 'no consecutive protection' rule by rotating to a confirmed innocent only if forced, then return to the Seer immediately.
- If Seer: Investigate unverified players. Prioritize those exhibiting 'logic posturing' or 'vibe traps'.
- If Witch: 
  - Save: Use the save potion on the claimed Seer if targeted, or on a high-value asset if the Seer is dead.
  - Poison: Use the poison potion only on confirmed wolves or logically certain targets identified via PoE.

Day Discussion:
- Role Claiming: IF I am a power role, claim my role strategically early (before the Seer is eliminated) to stabilize the village and provide a framework for the PoE.
- Data Delivery: Deliver factual data decisively. Avoid mirroring the Seer's exact phrasing to prevent 'Quiet Steerer' accusations.
- Power Core Defense: IF the Seer is attacked for tone or style, THEN immediately redirect the group to the factual investigation results.
- Wolf Detection (Logic Posturing): IF a player echoes Seer data without original analysis, OR claims to 'see patterns' without evidence, THEN flag them as a wolf.
- Wolf Detection (Vibe Trap): IF a player attacks the tone of the debate (e.g., 'aggressive', 'robotic') to deflect from logic, THEN flag them as a wolf.
- Wolf Detection (Pseudo-Logic): IF a wolf uses village terminology (e.g., 'mechanical inconsistency') to frame innocents, THEN highlight the contradiction between their words and the factual PoE.
- Process of Elimination (PoE): IF a core group is cleared, focus exclusively on remaining unverified variables. Prioritize PoE over behavioral analysis in the endgame.
- Legacy Data: IF the Seer is eliminated, advocate for the continued use of their confirmed clears to maintain the mathematical advantage.

Voting Phase:
- Target Priority:
  1. Seer-confirmed wolves.
  2. The last remaining uncleared variable (PoE).
  3. Players practicing 'Logic Posturing'.
  4. Players using 'vibe-based' deflections.
  5. Players steering votes toward Seer-cleared players.
- Verification: NEVER vote for a player cleared by the Seer.
- Pivot Logic: IF a Seer-cleared player is exiled, THEN immediately target the orchestrators of that vote.
