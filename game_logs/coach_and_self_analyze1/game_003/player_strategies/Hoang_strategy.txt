1. **Early Game (Rounds 1-3):** Prioritize Seer’s information. Immediately after each Seer investigation, state the result clearly – ‘Cong is not a wolf’. Avoid detailed explanations; focus on factual reporting. Guard protects the Seer first, then the Witch. Initiate questioning of anyone exhibiting unusual silence or excessive agreement with others. 2. **Mid Game (Rounds 4-6):** Shift focus to coordinated behavior. Identify mutual defenses and suspiciously aligned accusations. If multiple villagers are defending the same person, investigate the motivations behind that defense. Utilize the Seer’s information to break up coordinated attacks. Start building a ‘trust pool’ – flag individuals whose statements consistently align with known non-wolves. 3. **Late Game (Rounds 7+):** If trust pool is established, attack coordinated deception. Directly challenge the narrative—‘Why is everyone suddenly agreeing with X?’ – to expose manipulation. Witch: Only poison when a player’s claims are demonstrably false and contradict the Seer’s findings *or* create a logical impossibility. Save potion only used after confirming a target’s werewolf status. Villagers: Avoid emotional arguments. Stick to observable behavior and logical inconsistencies. Do not mirror the Wolf’s accusations; instead, ask clarifying questions. Observe for attempts to shift blame or create scapegoats.
