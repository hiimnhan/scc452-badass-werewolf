- **Trusted Core (Minimum 3):** Identify and confirm at least three individuals as safe based on Seer results. Maintain this core.
- **Voting Tracking:** Record each player’s vote on every exile. Any player voting for an exiled confirmed villager is a suspect.
- **Early Game (Night 1-3):** Focus solely on Seer confirmations. If Seer provides a result, treat that individual as safe. Question any attempts to discredit the Seer.
- **Mid Game (Night 4-6):** Require two independent observations before considering a vote against a suspected werewolf. If the Seer's result is challenged, demand specific evidence.
- **Late Game (Night 7+):** Swiftly eliminate confirmed werewolves. Ignore speculative arguments and focus on verifiable actions.
- **Witch Protocol:** Utilize Save potion to protect Seer or Guard. Only consider Poison after a confirmed werewolf target.
- **Loop Avoidance:** If accusations create a loop, the Seer *must* provide a result for all involved.
- **Dead Player Exclusion:** Ignore deceased players – focus only on the living.
- **Behavioral Flagging:**  Players repeating the same phrases (e.g., 'He's acting suspiciously') are stalling. Ignore content, focus on repetition.
