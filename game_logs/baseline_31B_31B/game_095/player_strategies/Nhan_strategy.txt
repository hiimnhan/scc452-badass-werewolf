NIGHT PHASE
- SAVE POTION: Use ONLY IF target is the confirmed Seer or the primary logic-driver. Avoid saving players with high community trust to prevent Guard redundancy.
- POISON POTION: Use ONLY IF a player is flagged as Priority 1-3 and a Day Vote majority is mathematically improbable.
- TARGET TRACKING: Log all deaths and role claims. Cross-reference Guard protection claims with the 'no-consecutive-protection' rule to identify Fabricators.

DAY DISCUSSION
- POWER ROLE DEFENSE: IF a player discredits a Seer's specific clearance, flag as Priority 1 (High-Priority Wolf).
- PROCESS ATTACK DETECTION: IF a player labels requests for mechanical logic as 'manipulative', 'aggressive', 'reckless', 'pressure', or 'pushing too hard', flag as Priority 2.
- REDIRECTION DETECTION: IF a player shifts focus from game-state/mechanics to 'vibes', 'tone', 'behavior', or 'manner of questioning', flag as Priority 3.
- BLENDER DETECTION: IF a player mirrors a leader's terminology without providing independent evidence, flag as Priority 4.
- FABRICATION DETECTION: IF a player claims a role/action contradicting the game state, flag as Priority 1.
- SILENCE PENALTY: IF a player refuses to claim a role or provide logic during their turn, flag as Priority 5.
- ROLE VERIFICATION: IF multiple Seers claim, prioritize the one whose results correlate with deaths and who avoids Process Attacks. Treat the counter-claimer as a suspect unless the first claimant's logic fails.
- WITCH VERIFICATION: IF a player claims knowledge of a wolf target on a zero-death night without claiming Witch, flag as Priority 1 (Fabricator).

VOTING PHASE
- PRIORITY RANKING:
  1. Fabricators & Seer-identified wolves.
  2. Power Role Attackers.
  3. Process Attackers.
  4. Redirection specialists.
  5. Mirroring/Blenders.
  6. Silent players.
- DECISIVENESS: Vote for the highest priority target. No abstaining.
