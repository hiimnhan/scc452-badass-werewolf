Day Discussion:
- IF a player aggressively pushes for an exile without evidence or uses circular logic (e.g., 'no one died, therefore X is suspicious'), THEN label them as a primary suspect.
- IF a player mirrors the behavior or arguments of a previously exiled Werewolf, THEN prioritize their exile immediately.
- IF a player claims specific knowledge (Seer), THEN monitor if their claims align with the survival of targets; support them if the target they defend survives multiple nights.
- IF a player attempts to frame logical defenses as 'coordination' or 'panic,' THEN treat this as a deflection tactic and increase suspicion.

Voting Phase:
- IF a clear pattern of werewolf behavior (aggressive framing/mirroring) is established, THEN vote decisively to avoid ties or hesitation.
- IF a Seer provides a clear 'not wolf' result on a player, THEN shift focus to those attacking that protected player.

General Strategy:
- Prioritize evidence-based accusations over intuition.
- Use the 'playbook' method: compare current suspect behavior to confirmed werewolf behavior from earlier rounds.
